# 出力形式: ASCII

チャット・issue・PR 本文・Markdown にそのまま貼れる。breadboard や thumbnail ボードを手早く出すのにも向く。ただし表現できる情報が少ないので、優先度（大きさ）の差は記号や太字ではなく**占める面積と位置**で表す。

## 書き方

- 必ずコードブロック（`````text`）に入れる。等幅フォントでないと崩れる
- 罫線は `+ - |` の ASCII に統一する。`┌─┐` などの罫線素片は、環境によって幅が半角 1 つ分にならず崩れることがある（使う場合はファイル内で統一し、混ぜない）
- 幅の目安: **モバイルは 40 列**、**PC は 100 列**（Markdown のプレビューで横スクロールが出ない上限が 100 列前後）。端末枠の外枠から測る
- 1 画面は 40 行程度までにする。それ以上は画面を分けるか、「（以下、同じ形の行が 20 件）」のように省略を明記する

## 日本語の幅に注意

**全角文字は 2 列分の幅を取る**。日本語ラベルを入れると右側の罫線がずれやすい。

- ラベルを入れた行は、全角 1 文字 = 2 列として数え、右端の `|` の位置を揃える
- 書いたら、各行の表示幅（全角 2・半角 1）が同じかを確かめる。手作業で不安なら、表示幅を数えるワンライナーで確認する:

  ```bash
  # 各行の表示幅を出力する（East Asian Width が W / F の文字を 2 列として数える）
  python3 -c 'import sys,unicodedata as u;[print(sum(2 if u.east_asian_width(c) in "WF" else 1 for c in l.rstrip("\n")), l, end="") for l in open(sys.argv[1])]' wireframe.txt
  ```

- 幅を揃えるのが難しい場所（長い日本語の文）は、枠の中に短いラベルを置き、詳細は枠の外の注釈に回す

## 記号の決まり

ワイヤーフレームの冒頭か末尾に凡例を付ける。

| 記号 | 意味 |
| --- | --- |
| `[ ラベル ]` | ボタン（`[[ ラベル ]]` は主要操作） |
| `[____________]` | テキスト入力 |
| `[ 選択肢 v ]` | セレクト |
| `( ) / (*)` | ラジオボタン（未選択 / 選択） |
| `[ ] / [x]` | チェックボックス |
| `+--------+` で囲み、中に `IMG: 商品写真` | 画像プレースホルダー（何の画像かを書く） |
| `=====` | タブの選択中を示す下線 |
| `(1)` | 注釈の番号マーカー |
| `...` | 省略（何を省略したかを書く） |

## 例: モバイル（40 列）

```text
+--------------------------------------+
| 9:41                          ||| [] |
+--------------------------------------+
| <  注文内容の確認                    |
+--------------------------------------+
| お届け先                    [ 変更 ] |
| 山田 太郎 / 東京都渋谷区...          |
|--------------------------------------|
| +------+ ワイヤレスイヤホン          |
| | IMG  | 1 点            ¥12,800     |
| +------+                             |
|--------------------------------------|
| 小計                       ¥12,800   |
| 送料                          ¥0     |
| 合計                       ¥12,800   |
|                                  (1) |
|                                      |
| [[        注文を確定する        ]]   |
|                                  (2) |
+--------------------------------------+

(1) 合計はボタンの直前に置き、押す前に金額を必ず目にする配置にする
(2) 親指の届く下側に固定。キーボードは出ない画面なので隠れない
```

## breadboard と thumbnail ボード

- breadboard は罫線を使わず、`structure-and-annotation.md` の「breadboard」の書式で書く
- thumbnail ボードは、各案を小さな枠（30 列程度）で横に 2〜3 個並べるか、縦に並べ、各枠の下に案名とトレードオフを 1 行で書く

## 確認

- [ ] 全行の表示幅（全角 2・半角 1）が揃い、右端の罫線がずれていない
- [ ] コードブロックに入っている。凡例がある
- [ ] モバイルは 40 列、PC は 100 列を超えていない
- [ ] 注釈番号と説明が 1 対 1 で対応している
